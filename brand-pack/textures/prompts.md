# Textures — фоны, паттерны, атмосферные накладки

Модель: **nano_banana_pro**. Соотношение: 1:1 (тайлится) и 16:9 (фон секции).

## Фоны секций (3-4 шт.)
### 1. Щётчёный алюминий
```
Seamless tileable texture of brushed aluminum with fine directional grain,
cold light raking across creating subtle linear highlights, matte steel
#4B4E54 and warm fog #C9C7C1 tones only, no scratches or dirt, extremely clean,
studio-neutral.
```

### 2. Полированный тёмный бетон
```
Seamless tileable texture of dark polished concrete with faint trowel marks
and subtle reflective sheen, void black #0A0A0B and graphite #1C1D20 tones,
soft cold light gradient across the surface, architectural material photography.
```

### 3. Тонированное стекло
```
Seamless tileable texture of dark tinted glass with faint fingerprint-free
reflections and a subtle cold light gradient, graphite #1C1D20 to void black
#0A0A0B, minimal, almost abstract.
```

### 4. Чёрный композит/сатин-металл
```
Seamless tileable texture of satin black composite material with a very fine
woven micro-pattern, matte steel #4B4E54 highlights, no visible carbon-fiber
diamond weave (avoid racing cliché), subtle and premium.
```

## Паттерн — радиаторная решётка / протектор
```
Abstract geometric pattern inspired by a radiator grille and tire tread lines,
thin precise repeating vector lines, warm fog #C9C7C1 lines on void black
#0A0A0B background, seamless tileable, works as a subtle section divider
background, extremely minimal, not busy.
```

## Атмосферные накладки (screen-blend, для оверлея на видео/hero)
### Лёгкий пар/дымка
```
Wisps of thin cold-toned fog/steam drifting diagonally, isolated on pure black
background for screen-blend compositing, soft edges, no color tint, subtle
density, high resolution, loopable motion feel even as a still.
```

### Световая дымка/лучи
```
Soft diagonal shafts of cold white-grey light haze with fine floating dust
particles, isolated on pure black background for screen-blend compositing,
subtle and cinematic, no lens flare artifacts, no color tint.
```

Избегать во всех: цветные тона (кроме указанных hex), видимый шум/зерно, карбоновый ромбовидный паттерн, глянцевый градиент "пластик".
